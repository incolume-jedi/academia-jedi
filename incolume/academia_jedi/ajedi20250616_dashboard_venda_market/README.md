

# Dash Sales Analyzer
Este é um projeto em que ensinamos a construir um Dashboard para análise de vendas de uma rede de Supermercados.

![3](https://user-images.githubusercontent.com/63136680/171271398-0e689c2f-0fbb-48c6-9ff8-5a79bdfd42f0.jpg)

## Escopo

Dependências originais:

  - dash==2.3.0
  - dash-auth==1.3.2
  - dash-bootstrap-components==1.0.3
  - dash-bootstrap-templates==1.0.5
  - dash-core-components==2.0.0
  - gunicorn==20.1.0
  - numpy==1.21.5
  - pandas==1.3.5
  - plotly==5.5.0

dash                      3.0.4

## 🔧 Funções

- Criar gráficos personalizados com os dados comerciais de uma empresa
- Consumo de base de dados
- Análise de dados de acordo com parâmetros específicos
