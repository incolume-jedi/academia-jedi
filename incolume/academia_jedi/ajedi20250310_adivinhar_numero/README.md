## Problema

**Jogo adivinhar número**

O programa sorteia um número aleatório secreto. O usuário informa um palpite, e o programa informa se o usuário acertou ou não. Caso o usuário não acertou o programa dá uma dica se o número é maior ou menor. E repete até 3 vezes.


## Resultado esperado

O programa funcional
