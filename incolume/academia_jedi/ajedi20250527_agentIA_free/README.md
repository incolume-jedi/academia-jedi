Video no youtube disponível em https://www.youtube.com/watch?v=rNVdldejojk.

Links Importantes:
- Git: https://git-scm.com
- Python: https://www.python.org/
- GitHub: https://github.com/browser-use/web-ui
- Openrouter: https://openrouter.ai/

Conta criada em openrouter e chave gerada com sucesso.

COMANDOS:

```bash
git clone https://github.com/browser-use/web-ui
cd web-ui
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
playwright install
```

Para executar: 

```bash
python webui.py --ip 127.0.0.1 --port 7788
```
Configuração extra:

    CHROME PATH: "C:\Program Files\Google\Chrome\Application\chrome.exe"
    CHROME_USER_DATA="/Users/YourUsername/Library/Application Support/Google/Chrome"
    (NÃO ESQUEÇA DE TROCAR 'YourUsername' PELO SEU NOME DE USUÁRIO DO WINDOWS)
